Streamplace beyond link parsing: `@atmo-dev/kit/streamplace-data` has types, API reads for live streams and videos, and chat text helpers (links, mentions, reactions), with no UI imports. `@atmo-dev/kit/streamplace` adds `Channel`, one streamer's live state and chat over a single socket, writing through an app-supplied `RecordWriter`.
